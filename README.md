## 📖 Overview

**Portfolio Website** is a personal portfolio application built with the MERN stack (MongoDB, Express, React, Node.js). It showcases my skills, projects, and experience as a Full Stack Developer and AI Engineer.

> 🎯 **Purpose:** Personal portfolio to showcase work and connect with recruiters/clients

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 👤 **User Profiles** | Create and manage user profiles with username, email, and quote |
| 📝 **Contact Form** | Demo endpoint for user data submission |
| 🗄️ **MongoDB Database** | Persistent storage with Mongoose ODM |
| 🌐 **REST API** | Express.js backend with CORS enabled |
| ⚛️ **React Frontend** | Client-side React application |
| 🔧 **Environment Config** | Dotenv for environment variable management |

## 🚀 Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/Aman-746/portfolio-website.git
cd portfolio-website
```

### 2. Install Backend Dependencies

```bash
npm install
```

### 3. Install Frontend Dependencies

```bash
cd client
npm install
cd ..
```

### 4. Environment Variables

Create a `.env` file:

```env
PORT=5000
DB=mongodb+srv://<username>:<password>@cluster.mongodb.net/<database>
```

### 5. Run the Application

**Start backend:**

```bash
npm start
# or for development:
npm run server
```

**Start frontend (in another terminal):**

```bash
npm run client
```

**Run both concurrently:**

```bash
npm run dev
```

Backend: `http://localhost:5000`  
Frontend: `http://localhost:3000`
